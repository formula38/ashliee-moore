## How to use

1. Fill `[BRACKETS]` and delete unused options.
2. Export to PDF or Doc when sending externally.
3. Keep signed PDFs in a private folder (Drive / Dropbox), named `YYYY-MM-DD_client_document.pdf`.
4. Log every signed booking on the weekly scoreboard (`09-weekly-scoreboard.md`).
