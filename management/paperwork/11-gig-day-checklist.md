# Gig-day checklist (modeling)

## When booking confirms

- [ ] Deal memo signed / email “Confirmed” saved  
- [ ] On shared calendar with address + call time  
- [ ] Deposit received (if required)  
- [ ] Concept checked against **no sexualized work** rule  

## Night before

- [ ] Call sheet / address / parking reviewed  
- [ ] Outfit / heels / nude + black heels packed as needed  
- [ ] Steamer / lint roller / fashion tape / safety pins  
- [ ] Snacks, water, phone charger, portable battery  
- [ ] Makeup wipe + blotting papers  
- [ ] Alarm + travel buffer set  
- [ ] Emergency contact shared with Triple 8  

## Call day

- [ ] Leave with buffer for traffic  
- [ ] Check in with Manager on arrival  
- [ ] Confirm wrap / pickup plan  
- [ ] Capture 5–10 behind-the-scenes or beauty stills (or designate shooter)  
- [ ] Note designer / MUA / photographer handles for credits  

## Within 7 days after

- [ ] Media dropped to shared Google Photos album  
- [ ] Invoice sent if balance due  
- [ ] Thank-you / follow-up to client  
- [ ] Log on weekly scoreboard (cash / trade / enjoyment)
