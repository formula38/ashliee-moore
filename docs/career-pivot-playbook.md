# Ashliee Moore — Career Pivot Playbook

Exploration doc for scaling, expanding, or pivoting her existing stack — **model · chef · promoter** — into clearer, more lucrative lanes.

**Current footprint:** Sacramento runway / fashion shows (Be ExquisiteU, Sac Fashion Pro), culinary hosting, event presence (LiBush Africa, VVS Studios, Old Sac), Instagram [@ashliee007](https://www.instagram.com/ashliee007/), portfolio at ashliee-moore.com.

---

## 1. Modeling lanes (from your brief)

These are not mutually exclusive. Most working models stack **two** of them.

| Lane | What it pays for | Best fit for Ashliee if… | Reality check |
|------|------------------|--------------------------|---------------|
| **Editorial** | Artistic campaigns, magazines, lookbooks, “published means” | She wants prestige, designer relationships, strong portfolio images | Lower day rates early; reputation compounds; needs intentional test shoots + agency or strong self-rep |
| **Commercial** | Catalogs, e-comm, ads, brand websites (ASOS / Macy’s energy) | She wants steadier bookings and clearer invoices | Highest volume path for most models; Sacramento + remote e-comm castings are reachable |
| **Fit** | Living mannequin for designers / pattern teams | She has consistent measurements and likes behind-the-scenes studio work | Steadier hourly/day rates; less glam; strong bridge into design/brand relationships |

### How to position each on the site / booking form

- **Editorial** → “Fashion / editorial / lookbook”
- **Commercial** → “Brand / catalog / campaign”
- **Fit** → “Fit / sample / design development”

Right now the booking form only says “Modeling.” Splitting inquiry types later makes it easier for clients to self-select — and for Ashliee to price differently.

### Practical next moves (modeling)

1. **Measurements + sizing sheet** (bust/waist/hip, height, shoe, dress size) — required for commercial + fit.
2. **Digitized comp card** (headshot, full body, 2–3 selects, contact, stats) linked from the site.
3. **Two test shoots with clear jobs:** one commercial (clean light, product-friendly); one editorial (story, roses / existing brand language).
4. **Casting cadence:** Model Mayhem alternatives, local Sac designer fittings, Bay Area day trips, agency submissions once the book is tight.
5. **Rate card (private):** e.g. half-day / full-day / usage rights — even a simple PDF beats negotiating from zero every time.

## 2. The unfair advantage: stack the three pillars

Most models only sell looks. Ashliee already sells **looks + hospitality + crowd**. That combo opens higher-ticket work than walk-only gigs.

```
Model          → visual authority, wardrobe fluency
Chef / host    → table energy, taste, content that converts
Promoter       → rooms, brands, ticketed nights, partnerships
        ↓
   “Lifestyle talent” / brand host / experience producer
```

**Highest-leverage identity (working title):**  
*Fashion-forward culinary host and brand presence* — not “model who cooks on the side,” and not “promoter who models sometimes.” One brand, three proof points.

## 3. Lucrative expansion paths (ranked by leverage)

### A. Brand ambassador / regional face (near-term cash + comps)

- Local / regional fashion, beauty, F&B, lifestyle brands.
- Deliverables: appearances, IG content, in-store events, soft openings.
- Why it fits: she already does presence for studios and cultural brands.
- Scale: start retainer-ish ($ / month for X posts + Y appearances) instead of one-off free “exposure.”

### B. Culinary hosting as a productized offer

- Package: **“Ashliee Hosts”** — hibachi nights, private dinners, brand tasting pop-ups.
- Sell to: restaurants wanting a draw, private clients, brand launch dinners.
- Upsell: styled looks for the night (modeling + hosting in one invoice).
- This is often more bankable locally than pure editorial early on.

### C. Event / experience producer (promoter → producer)

- Move from “promoting someone else’s night” to **owning or co-owning** formats: fashion dinner, runway + tasting, rose-themed brand salon.
- Revenue: tickets, sponsor packages, brand tables, content rights.
- Risk: more ops. Start as co-producer with a venue that already trusts her.

### D. Content + creator monetization (parallel track)

- Vertical: fashion + food + Sacramento nights — distinct from generic GRWM.
- Monetize: brand deals, affiliate, paid collabs, eventual digital products (hosting guide, style lookbooks).
- Needs: consistent posting system + media kit with rates (even rough).

### E. Fit-to-stylist / brand consultant adjacent (medium-term pivot)

- Fit model relationships → stylist assistant → personal stylist / wardrobe consulting for events.
- Or: brand “muse” retainers with emerging Sac / Bay designers.
- Uses runway credibility without relying only on being cast.

### F. Agency / talent-side pivot (longer pivot)

- If booking herself teaches the market: **talent booking / casting liaison** for Sac fashion + hospitality events.
- Or: boutique “presence talent” roster she curates (models who can also host).
- Leverages promoter skill more than face time alone.

## 4. Pivot matrix — pick a primary + a secondary

| Strategy | Primary money | Secondary proof | Avoid for now |
|----------|---------------|-----------------|---------------|
| **Published model** | Commercial + selective editorial | Fit gigs for cash flow | Random unpaid “collabs” without usage clarity |
| **Host-first talent** | Culinary / brand hosting packages | Fashion looks for those nights | Spreading thin across every party |
| **Experience brand** | Ticketed / sponsored nights | Modeling + kitchen as content | Owning venues before owning a format |
| **Creator-led** | Brand deals + affiliates | Portfolio site as media kit | Chasing virality without offers |

**Recommended default for the next chapter:**  
**Host-first talent** with a **commercial modeling** spine. Editorial becomes portfolio fuel, not the only paycheck. Promoter work becomes **owned or co-owned experiences**, not only amplifying others.

## 5. 90-day experiment plan

### Days 1–30 — Clarify the offer

- [ ] Write a one-page rate sheet (modeling day rates + hosting package + appearance fee).
- [ ] Add measurements + comp card PDF to the site (or a private link).
- [ ] Split booking inquiry types: Editorial / Commercial / Fit / Culinary host / Brand appearance.
- [ ] List 20 warm contacts (designers, restaurants, studios, promoters) already in her orbit.

### Days 31–60 — Prove demand

- [ ] Book 2 paid or trade-with-clear-usage shoots (1 commercial, 1 editorial).
- [ ] Sell or soft-launch **one** hosted night (restaurant partner preferred).
- [ ] Publish a simple media kit (bio, stats, select images, past logos, contact).
- [ ] Pitch 5 brands for ambassador / appearance work with a specific deliverable list.

### Days 61–90 — Double down on what paid

- [ ] Drop the lane that produced zero interest.
- [ ] Productize the winner (named package + fixed price + what’s included).
- [ ] Revisit agency submission **only if** commercial book + rates are real.
- [ ] Update portfolio site copy to match the winning positioning (not three equal hobbies).

## 6. Pricing intuition (starting frames, not gospel)

Adjust for market, usage, and exclusivity. These are conversation starters.

| Offer | Starting frame |
|-------|----------------|
| Commercial half-day (local) | Session fee + usage bump for web/ads |
| Editorial / lookbook | Day rate or image license; trade only if tearsheets + rights are written |
| Fit model | Hourly / half-day; measurements locked |
| Culinary host appearance | Flat appearance fee + travel; F&B comps separate |
| Brand ambassador (monthly) | Retainer for set posts + 1 appearance |
| Co-produced event | Guarantee vs. door split + sponsor line items |

**Rule of thumb:** If a “collab” has no fee, it must have **portable assets** (photos she owns or can use commercially) or **a named credit that opens the next paid door**.
